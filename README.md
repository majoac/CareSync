# **CareSync**

Creadoras: Maria Celeste Román, Anahí Hernandez, Maria José Arevalo.

● Descripción: CareSync es un sistema integral de administración hospitalaria, desarrollado en tercer semestre simultáneamente en las materias de Bases de Datos I y Desarrollo de Sistemas III. En este proyecto se implemento una interfaz gráfica de usuario completa utilizando JavaFX, logrando conectar de manera eficiente el diseño visual interactivo con una base de datos relacional para gestionar los ingresos de pacientes. 

Para acceder al sistema se ingresa el usuario developer y la contraseña puna1905.
El menu principal se ocultara al abrir un modulo y regresara al cerrarlo.
